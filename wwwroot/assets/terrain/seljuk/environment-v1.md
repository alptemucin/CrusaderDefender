# Çevre assetleri v1

Yerleşik Imagegen ile üretilen iki şeffaf 2×2 atlas:
- `trees-atlas-v1.png`: meşe, çam, geniş yapraklı ağaç, sedir.
- `mountains-atlas-v1.png`: dört dağ silueti.

## Ağaç promptu

Use case: stylized-concept. Asset type: transparent environment tree sprite atlas for an isometric cartoon fantasy tower-defense game. Create ONE square PNG with exact 2x2 equal square cells. Each cell contains ONE different complete tree, all aligned ground-contact point bottom center at 90% cell height, entire crown inside cell with 10% margin. Upper-left rounded oak, upper-right slender pine, lower-left clustered rounded broadleaf tree, lower-right broad cedar. Isometric three-quarter view matching hand-painted fantasy strategy units. Dense moss and sage green leaves, warm olive highlights, dark teal shadows, readable brown trunks, confident dark fine outlines, chunky cartoon forms, rich painterly shading, no photorealism. No platforms, no grid, no text, no landscape, no rocks. Small soft contact shadow only, genuinely transparent background and transparent gutters. Trees are exterior decoration along the game-map border. Identical scale and consistent lighting.

## Dağ promptu

Use case: stylized-concept. Asset type: transparent distant mountain environment atlas for an isometric cartoon fantasy tower-defense game. Create ONE square PNG with exact 2x2 equal square cells. Each cell contains ONE separate full mountain group sitting on a common flat base: upper-left twin craggy peaks, upper-right a large rounded rocky mountain, lower-left three layered alpine peaks, lower-right an elongated ridge. Entire silhouette contained in each cell with 10% transparent margins; grounded bottom center at 90% cell height. Isometric three-quarter view, hand-painted fantasy strategy game art, chunky cartoon rock planes, desaturated grey-blue and moss-grey stone, subtle pale cold highlights and dark slate outlines, green foothill patches. Far scenery should be less saturated than foreground trees. Crisp silhouettes, no fog background, no sky, no buildings, no text, no grid lines, no platforms. Genuine alpha transparency between and around four independent sprites.
